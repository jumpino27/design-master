Design Master 1.1.1 adds a crimson dark interface, a new logo across the application and installers, and a redesigned project library. The heading, project actions, filters, and search stay visible while scrolling.

Four finished showcases are included: Nexora, Elevate Studio, MetricFlow, and VYBE. They contain 23 rendered screens and extracted assets, with brand kits, design specifications, and coding-agent handoffs. Browsing them does not require an API key. Existing projects and edits remain intact when upgrading.

Starter suggestions now send immediately. Clarification asks one question at a time with three choices and a custom-answer box. Each response informs the next question, and generation begins once the brief is clear. Duplicate answers are rejected, and failed requests remain retryable. Dialogs and handoff panels now scroll correctly in smaller windows.

Downloads include macOS Apple Silicon DMG and app archive, Windows x64 setup and portable ZIP, and Linux x64 DEB, AppImage, and shell installer. Check files against SHA256SUMS.txt. The macOS app is ad hoc signed and is not notarized. Windows packages are unsigned. Linux requires WebKit2GTK 4.1 and GTK3. Install the DEB with `sudo apt install ./design-master_1.1.1_amd64.deb`.

Generation requires your own OpenRouter key and incurs provider charges. Your API keys, workspace settings, and local usage history are not included in the showcases.
