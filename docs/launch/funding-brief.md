# Design Master funding brief

Design Master is an MIT-licensed Tauri application with a Rust/SQLite backend and a Next.js interface. It keeps project rules and generated design material in local storage, while generation requests use the user's OpenRouter account.

The current work includes native installers for macOS ARM64, Windows x64, and Linux x64; an update path through GitHub Releases; and portable design handoff exports.

A grant proposal could fund accessible keyboard workflows, installer testing, clearer asset provenance, and a documented provider interface. Any proposal should define concrete milestones, testing evidence, and a maintenance plan.

Before submitting a grant, the owner must supply the applicant's legal name or organization, residence or registration jurisdiction, requested amount, delivery period, and an approved budget. No user counts, revenue, organizational credentials, or funding commitments have been invented.

Payment profiles and public funding links must be verified before they are advertised as accepting contributions.
